Rapprochement clients Optimum / Cegid

Importez les exports d'un magasin pour faire ressortir automatiquement les écarts et les antériorités à justifier. Rien n'est envoyé sur un serveur — tout le traitement se fait dans votre navigateur.

1 — Importer les fichiers du magasin

Importez uniquement ce dont vous avez besoin : un seul rapprochement à la fois (par exemple les tiers-payants seuls) fonctionne très bien. Les fichiers Cegid doivent être exportés après lettrage : ils ne doivent contenir que les écritures non lettrées.

📂 Glissez ici tous les fichiers du magasin, dans n'importe quel ordre L'outil reconnaît automatiquement le type de chaque fichier (tiers-payants, chèques, avoirs, acomptes, virements, CB — Optimum comme Cegid). Vérifiez et corrigez si besoin juste en dessous.
Phase 1 — moteur de rapprochement. Le suivi des actions du magasin d'un mois sur l'autre (statuts, commentaires, accès par code) sera ajouté dans une phase 2, une fois ce rapprochement validé.
